# Ruin Runner

Ruin Runner is an original Temple Run-inspired endless runner built in Python with Pygame. It includes:

- smooth lane switching controls
- jumping and sliding movement
- coin-like pickups and power-ups
- enemy chase pressure from the Shadow Guardian
- score tracking, lives, and win/lose flow
- stylized arcade graphics made from shapes and gradients

Game name options
- Ruin Runner
- Ancient Escape
- Cursed Sprint
- Artifact Chase

Enemy
- Shadow Guardian

Power-ups
- Shield
- Magnet
- Speed Burst
- Slow Time

Controls
- Left / A: move left
- Right / D: move right
- Up / W: jump
- Down / S: slide
- Space: trigger boost or active skill effect
- Enter: start or restart
- ESC: quit

Installation

1. Make sure Python 3.10+ is installed.
2. Install dependencies:
   python -m pip install -r requirements.txt
3. Start the game:
   python main.py

Notes

This is an original game inspired by the style and feel of endless runners, but it does not reuse the exact copyrighted assets or code of Temple Run.
